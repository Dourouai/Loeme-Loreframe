# Loeme Loreframe HARNESS

> 已确认需求与产品约束。只有用户明确确认过的内容进入本文件；讨论中的方案先不写入正式段落。

## 1. 产品定位

Loeme Loreframe 是面向有声图、短故事、长故事视频生产的软件工作台。第一期目标是先支持现有短故事和太平广记类内容的本地生成流程。

## 2. 第一期目标

- 用对话完成文案确认、分章、图片提示词调整、配音生成和预览导出。
- 支持模板化视频风格，但模板只在新建项目时选择，不在工作台常驻展示，也不在顶部切换当前项目模板。
- 支持 DeepSeek API、Codex CLI、腾讯云 TTS、本地音乐库等配置入口。

## 3. 已确认决策记录

### 2026-07-02 · 项目 / 视频 / 模板关系

- 项目不是单条视频，而是长期内容系列 / 栏目规则，例如“老沈短视频”和“太平广记”。
- 每个项目下面挂多期视频；每一期视频有独立文案、分章、图片、配音、字幕、输出文件和发布包。
- 项目保存长期规则：项目定位、观众、叙事口吻、默认视频模板、默认音色、默认配乐、画面风格、分章规则、输出规则和发布规范。
- 每期视频默认继承项目规则，但允许单期覆盖模板、音色、配乐、分章规则、画面风格和发布信息。
- 模板可以提供项目定位和项目默认值，但模板不是项目定位的最终来源；创建项目时，模板默认值复制进项目，之后由项目自己维护。
- 当前第一阶段优先覆盖真实业务流：贴文案或让 AI 写文案 → 对话确认 → 自动切分章节 → 生成图片 Prompt → 用户选择内置生成或外部生成后导入 → 配音 / 配乐 → 预览 / 输出。
- 后续自动化流水线必须建立在这个对话流程稳定之后逐步抽象，不能一开始就做全自动黑盒。

### 2026-07-02 · 分阶段开发方式

- 后续开发按小步可见成果推进；每一步都必须能在 Studio 中看到变化，并配一条手动测试路径。
- 第一批开发顺序：系列项目模型 → 项目下多期视频 → 对话生成 / 粘贴文案并切分章节 → 外部图片 / 音频导入状态 → 项目默认声音和配乐与单期覆盖 → 预览和输出包。
- 每个阶段可以先做静态 / 本地状态原型，再逐步接真实文件、CLI 和 provider。
- 文档必须明确“功能还在开发中，尚未功能闭环”，避免开源用户误以为当前版本已经能完整自动出片。

### 2026-07-02 · 对话优先与素材管理

- 创作对话不应该被设计成强制向导；它是自然语言入口，用来定义项目、优化已有模板、整理素材、解释素材状态和推进单期视频制作。
- 如果已经有合适模板，默认是优化当前模板；只有现有模板不适合时才创建新模板，或从稳定模板复制出一个派生版本。
- 用户可以先通过对话描述“把老沈短视频模板优化成更悬疑 / 把太平广记模板改成长视频叙事”，系统整理出项目定位、视频模板、画面风格、声音建议、素材要求和输出规范。
- 工作台重点之一是素材管理和展示：图片、音频、字幕、音乐、参考资料、外部生成素材都要能被归档、预览、标记状态并关联到项目 / 单期视频 / 章节。
- 不要求用户必须按“写文案 → 分章 → 生成图 → 配音”的固定引导流程走；系统应该允许用户先导入素材、先定义模板、先贴文案，或边对话边补齐资产。
- 自动化流水线是后续从稳定对话流程中抽象出来的能力，不是一开始就限制用户操作路径的前提。

### 2026-07-02 · Studio Agent 对话接入

- `npm run studio` 改为启动本地 Node 服务 `apps/studio/server.mjs`，不再只是静态文件服务。
- Studio 新增 `/api/chat`，前端创作对话会按顶部 Agent 选择调用 Codex CLI 或 DeepSeek API。
- Studio 对话默认走轻量模式，只发送用户问题和最小项目 / 模板标识；只有用户明确要开始执行、生成、优化、修改、检查、整理素材等工作时，才加载完整项目、章节、素材和声音上下文。
- 当用户要求生成 / 切分章节时，Agent 回复必须包含 `json loeme-chapters` 机器可读块；前端解析成功后写入当前项目 `chaptersData`，并刷新章节目录、预览和右侧详情。
- “生成 3 个章节 / 拆成 4 段 / 生成分镜”等自然语言都属于章节生成意图，即使当前对话作用域停留在图片，也必须自动写入章节目录并切回文案 / 章节流程。
- 前端同时兼容 Markdown 表格和 `CH-01 / 第1章 / 1.` 小节格式，避免 Agent 未严格输出 JSON 时章节目录不更新。
- 章节级“图片生成”必须跟随当前项目模板画布尺寸和比例，例如竖屏模板使用 `1080×1920 · 9:16`，横屏模板使用 `1920×1080 · 16:9`；Agent 只输出可用于生图工具的 Prompt，不假装已经生成图片文件。
- 右侧 / 当前章节里的“图片生成”点击后必须有明确反馈：更新章节图片状态、把带尺寸约束的任务发送给当前 Agent，并刷新分镜目录、预览和章节详情；Agent 返回最终图片 Prompt 后，只能替换当前章节的 `prompt` 字段和本地 Prompt 预览，不允许覆盖章节目录，并把图片状态标记为“本地预览已生成”。
- 在真实图片 provider 接入前，章节缩略图、视频预览背景和当前内容大图使用本地 Prompt 预览占位图：根据章节标题、旁白和图片 Prompt 的关键词生成不同的视觉氛围，不能所有章节共用同一张通用占位图；界面状态仍要清楚标注这是待生图 / Prompt 预览。
- 对话区里的 JSON、章节结构数据、配置数据和过长代码块默认折叠，只展示摘要；用户需要时再展开查看完整内容，避免机器数据撑开聊天框。
- Studio 新增 `/api/agents`，用于检测本机 Codex CLI 与 DeepSeek 环境配置状态。
- Codex 作为工作台对话 Agent 时，默认只返回建议 / 结构化草案；除非用户明确要求，不主动写文件或运行创作外的命令。
- DeepSeek API Key 仍从 Studio Settings 的本地配置或 `DEEPSEEK_API_KEY` 环境变量读取。

### 2026-07-02 · 预览播放第一阶段

- 第一阶段预览先做章节级播放体验：播放 / 暂停会驱动本地预览时间轴，不再只是切换状态文案。
- 播放头按当前视频总时长推进；到达章节时间段时自动切换当前章节、刷新预览画面和章节目录高亮。
- 进度条支持点击、拖动和键盘左右键定位；定位后同步当前章节。
- 当前阶段仍不是完整素材轨道编辑器，也不承诺真实音频、字幕、图片文件已经逐帧混合播放；后续 AE 式素材轨道会复用这套时间轴状态。

### 2026-06-30 · 项目新增与删除持久化

- 项目列表必须支持新增和删除；新增项目刷新后必须保留。
- 默认项目只是首次进入工作台的种子数据，用户删除默认项目后刷新不能重新带出。
- 项目删除需要确认弹窗；删除后同时移除该项目的本地对话线程和草稿状态。
- 项目允许删到空列表；空列表时工作台展示空状态，引导用户新建项目，而不是展示旧默认章节数据。
- 新建项目只创建项目壳和独立对话线程，不自动带出默认章节、默认画面或默认旁白；章节、文案、图片 Prompt 和配音任务必须通过项目对话生成后才展示。
- 新建项目在内容未生成前，视频预览、右侧章节目录和中间当前内容详情都展示“等待对话生成”的空内容状态。

### 2026-06-30 · 工作台滚动内容区与章节导航

- 中间生产区改为完整内容滚动列，顺序为：视频预览 → 全片声音与音乐 → 当前内容详情。
- 中间生产区只保留一条轻量滚动条，避免预览、声音配置和详情各自抢高度或出现多层内部滚动。
- 右侧侧栏改为章节目录 / 分镜导航，展示章节标题、时间、图片状态和配音状态，用于选择当前章节。
- 右侧章节目录的收起行为是侧边横向收起：收起后保留窄栏和竖排“章节目录”提示，中间工作区自动变宽；不是把目录内容向下折叠。
- 当前章节的画面、Prompt、标题、旁白文案和章节级操作从右侧移动到中间生产区的“当前内容”模块。
- 在默认宽度下不能产生横向滚动；小屏工作区需要收紧中间列和右侧章节栏宽度。

### 2026-06-30 · 全片声音与音乐展开规则

- “全片声音与音乐”外层展开时必须真正展示 Audio 和 Music 的配置字段，不能只露出 Audio/Music 标题行。
- 外层配置卡片高度跟随内部内容，不允许被父级网格行或 `overflow:hidden` 裁切。
- 外层收起时只保留卡片标题、说明和 global 状态；再次展开时同步展开 Audio 与 Music 两个配置段。

### 2026-06-29 · 顶部菜单边界

- 顶部菜单不展示项目名称输入；当前项目身份由左侧项目列表和对话上下文确认。
- 顶部 Template 入口用于打开“新建项目 / 选择模板”弹窗，不用于切换当前项目模板。
- 已进入工作台的项目不允许在顶部随手切换模板；如需换模板，应通过新建项目或后续明确的项目级重建流程完成。
- 对话区优先使用自然语言完成操作，暂时不展示“改文案 / 重分章节 / 补图片 / 生成配音”等快捷按钮。


### 2026-06-29 · 全片声音参数配置

- 全片声音配置需要支持 Provider 选择，第一期默认 Tencent Cloud TTS，并保留后续本地/第三方语音服务扩展位。
- 需要支持全片级 Voice / VoiceType 参数；Voice 面向用户命名，VoiceType 对应腾讯云等供应商的具体音色类型。
- 需要支持语速参数、情绪参数和旁白音量参数；这些参数作用于整条视频，不在章节中重复配置。
- 声音配置区优先作为全片参数面板展示；是否触发全片合成通过对话或后续明确的任务入口完成，不在分镜表中重复提供。
- 后续可以扩展“按旁白自动适配时长”，但第一期可以先作为禁用或待接入能力展示。

### 2026-06-29 · 工作区主区声音配置与章节侧栏边界

- 工作区主内容区的顺序调整为：视频预览 → 全片声音配置 → 分镜表。
- 全片 Audio 与 Music 都属于视频级设置，但必须拆成两个独立模块：Audio 管旁白服务、音色、语速、情绪和旁白音量；Music 管 BGM、音乐库和混音音量。二者不放在章节侧边栏，也不在每个章节重复选择，并分别支持收起。
- 章节侧边栏只保留当前章节信息：章节标题、图文内容、图片 Prompt、旁白文案。
- 章节侧边栏只提供三个章节级操作：优化文案、图片生成、配音生成。
- 分镜表用于浏览章节状态和选择章节，只展示章节图文摘要、时间、图片状态、配音状态；不展示“重分章节 / 补齐素材 / 生成配音”等操作按钮。

### 2026-06-29 · 项目级对话线程与项目栏收起

- 对话内容必须跟随当前项目走；每个项目拥有独立的对话线程、任务上下文和历史记录。
- 切换左侧项目时，中间对话框同步切换到该项目自己的消息、当前任务、输入框作用域和草稿内容。
- 项目侧边栏支持收起；收起后保留窄栏提示，不能影响当前项目内容、对话线程或右侧工作区状态。
- 这条是正式需求，不作为临时视觉效果处理。


### 2026-06-29 · 工作台布局落版

> 已被 2026-06-30「工作台滚动内容区与章节导航」更新：章节目录移动到右侧，当前章节详情移动到中间生产区。

- 工作台当前落版：左侧项目列表 → 项目对话 → 主工作区。主工作区为视频预览、可收起的全片声音配置、分镜状态表；右侧只展示当前章节详情和章节级细节操作。
- 分镜状态表是导航和状态观察区，不是操作区；章节操作统一放在右侧章节详情或通过对话触发。
- Audio 与 Music 是同一个全片级卡片组件里的两个配置段，折叠后分别保留“Audio · 全片配音”和“Music · 全片配乐”的一行摘要，不影响视频预览和分镜表浏览。

### 2026-06-29 · 顶部工具栏与 Audio/Music 配置边界

- 顶部模板入口不显示额外标题，只保留当前模板按钮；点击仍进入新建项目 / 模板选择流程，不切换当前项目模板。
- 顶部 Agent 只保留 Codex CLI 与 DeepSeek API 两个可切换选项，左侧显示 Agent，右侧为下拉选择。
- Settings 中 Audio 与 Music 拆分为两个模块：Audio 只配置语音服务接入，Music 只配置音乐库 / 第三方音乐源接入。
- 腾讯云 TTS 默认配置不保存默认音色和默认语速；音色、语速、情绪、旁白音量跟随项目或单条视频的声音方案选择。
- BGM、试听音量和混音音量不放在 Settings 默认配置里，统一进入工作台 Music 段和项目级音乐方案。

### 2026-06-29 · 工作台 Audio / Music 交互层级拆分

- 工作台交互层级上，Audio 与 Music 放在同一个“全片声音与音乐”卡片组件里，内部拆成两个 section；不能做成两张独立卡片。
- “全片声音与音乐”卡片支持外层收起；外层收起后只保留卡片标题、说明和 global 状态，不展示 Audio / Music 两个 section 标题行。
- Audio 卡片只处理旁白 / 配音：TTS Provider、项目级 Voice、供应商 VoiceType、语速、情绪、旁白音量。
- Music 卡片只处理背景音乐：音乐来源、本地或第三方音乐库、BGM 选择、音乐混音音量。
- 章节卡片只展示图片状态和配音状态，不展示 BGM 操作；BGM 的更换、试听和氛围调整统一走 Music 模块或对话指令。
- Settings 里的 Audio 是“服务接入配置”，工作台里的 Audio 是“项目级配音方案”，两者不能混淆；Settings 里的 Music 是“音乐库 / 第三方音乐源接入”，工作台里的 Music 是“当前视频配乐方案”。

### 2026-06-29 · 工作台右侧章节详情布局

> 已被 2026-06-30「工作台滚动内容区与章节导航」更新：右侧改为章节目录 / 分镜导航，不再承载章节详情。

- 工作台四列结构确认：项目列表、项目对话、中间生产区、右侧章节详情侧栏。
- 中间生产区只承载视频预览、全片 Audio/Music 卡片和章节目录。
- 旧版曾让右侧侧栏承载当前选中章节详情；此安排不再采用，章节详情已移动到中间当前内容模块。
- 章节目录仍在中间区，用于浏览和选择章节；章节详情不再占用中间区下方空间。
- 章节目录支持收起；收起后只保留标题和摘要行，中间生产区高度优先还给视频预览和全片声音与音乐卡片。
